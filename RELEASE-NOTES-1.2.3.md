Notestr Android 1.2.3 — bouton Copier dans les blocs de code.

Le champ de langage affiché en haut à droite des blocs de code est remplacé par un bouton Copier en mode Visuel. Il copie uniquement le texte du bloc dans le presse-papiers Android, en conservant les espaces, les lignes vides et les caractères spéciaux. La confirmation « Copié ! » apparaît après la copie. Le Markdown et le langage déjà renseigné restent inchangés ; le langage peut toujours être modifié en mode Markdown.

APK complet pour installation neuve ou mise à jour, signé avec le même certificat que les versions précédentes. Installation possible par-dessus sans désinstaller. Vérification ciblée des sources et de l’APK : aucune donnée personnelle du propriétaire ni clé privée détectée. Les valeurs cryptographiques des tests sont synthétiques.

Validation : 8 tests unitaires, tests navigateur et 3 tests Android de l’éditeur réussis. Les versions 1.2.1 et 1.2.2 restent disponibles, avec leurs tags et leurs téléchargements dans le README et le CHANGELOG.
