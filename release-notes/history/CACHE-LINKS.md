# Candidat local 3.6-test.23 — 1er octobre 2026

Les notes en cache sont déchiffrées et affichées avant la synchronisation des relais. Leur consultation est possible pendant celle-ci ; les actions de publication restent suspendues. Les signatures et le compte sont vérifiés. Le cache disque contient uniquement les événements chiffrés ; les résultats déchiffrés ne sont conservés qu’en mémoire pendant la session puis effacés au verrouillage. Le changement de compte efface aussi immédiatement la liste affichée.

Les liens HTTP/HTTPS en mode Visuel s’ouvrent dans le navigateur, sans navigation externe dans la WebView. Les clics par script et les autres schémas sont ignorés. Une confirmation protège les modifications non publiées, car quitter Notestr pour le navigateur déclenche son verrouillage habituel.

APK local, versionCode 23, aucune publication. Tester un démarrage hors ligne après une synchronisation réussie, ouvrir une note pendant la synchronisation et cliquer sur ses liens. Le mode Markdown demeure un champ de saisie.
